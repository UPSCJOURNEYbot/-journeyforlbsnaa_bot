#
# IMPORTANT — SINGLE BOT DEPLOYMENT
#   The deployed application runs ONE bot (see run.py). There is no separate
#   "creator bot" / "scheduler bot" pair anymore: quiz PLAYING commands run in
#   groups and private chats, while quiz CREATION commands are bridged and
#   only respond in private chat (they are enforced PM-only; help/features/
#   listquiz are the exceptions).
#
#   Block 1 = the DEFAULT menu (paste this into BotFather — safe in all chats).
#   Block 2 = the PRIVATE-CHAT creator menu. BotFather's /setcommands only sets
#   the default scope; to install Block 2 for PM only, call the Bot API
#   setMyCommands with scope {"type": "all_private_chats"} (e.g. via a one-off
#   script). Every command below exists in the current code; there are no
#   placeholders.

# ════════════════════════════════════════════════════════════════════════════
# BLOCK 1 — DEFAULT (all chats): PLAYING / GENERAL commands
# ════════════════════════════════════════════════════════════════════════════

start - Start the bot / launch a quiz: /start <quiz_id>
listquiz - Browse public quizzes
pollquiz - Run a quiz as live Telegram polls in this group
pollstop - Stop the running poll quiz
aiquiz - Generate and play an AI quiz on a topic
pdfquiz - Reply to a PDF to build a quiz from it
mix - Mix questions from several quiz IDs
weakquiz - Practise your weakest topics (personal revision)
mistakes - Review your recorded mistakes (personal revision)
stats - Show your XP, level and IST daily streak (alias: /xp)
xp - Alias of /stats: your XP, level and streak profile
leaderboard - Show the live top-10 leaderboard
result - Show your most recent quiz result
pause - Pause the running quiz (group admins)
resume - Resume a paused quiz (group admins)
stop - Stop the running quiz (group admins)
slow - Lengthen the per-question timer
fast - Shorten the per-question timer
normal - Reset the per-question timer to normal
schedule - Schedule a quiz auto-launch time
viewschedule - List this chat's scheduled quizzes
cancelschedule - Cancel a scheduled quiz
html - Toggle the interactive HTML result report for this chat
pdf - Toggle the PDF result report for this chat
trans - Translate the current question to another language
help - Show the full command reference
features - Show a short feature overview
